# loyal4studio.com

Website for **Loyal4**, the one-person game studio behind *Shift Survivors*.

Live at https://loyal4studio.com

- `index.html`: the whole site (fonts and images are embedded)
- `play/`: the free web demo of *Shift Survivors* in 3D, set at St. Overtime Medical Center (4 West): `index.html` plus the two character models
  (`nurse_f.glb`, `nurse_m.glb`). It is the Steam edition of the game (no real names, no leaderboard) with the 3D view added by the
  `tools/3d` scripts in the Shift-Survivors repo: `patch_needs.py`, then `patch_3d.py ... inline`.
- `og.png`: the image shown when the link is shared
- `licenses/`: font licenses (SIL Open Font License)
